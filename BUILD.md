# Сборка ThingTracker

Готовые файлы, которые пользователь скачал и запустил — без установки Python/Node.
Внутри каждого: React-интерфейс + Python-бэкенд (упакован PyInstaller) + Electron.

## Что получается

| Устройство | Файл | Установка |
|-----------|------|-----------|
| Windows | `ThingTracker <версия>.exe` (portable) | нет, просто запуск |
| Windows | `ThingTracker Setup <версия>.exe` | обычная установка |
| macOS | `ThingTracker-<версия>.dmg` | перетащить в Applications |
| Linux | `ThingTracker-<версия>.AppImage` | нет, `chmod +x` и запуск |
| Linux | `thingtracker_<версия>.deb` | `sudo dpkg -i` |
| Телефоны | — | PWA (см. ниже) |

## ⚠️ Кросс-компиляции нет
PyInstaller и electron-builder собирают только под ТУ ОС, на которой запущены.
Windows-файл — на Windows, Mac — на Mac, Linux — на Linux. Два пути:

### A. Локально (под свою ОС)
Windows:  `powershell -ExecutionPolicy Bypass -File build.ps1`
Mac/Linux: `bash build.sh`
Результат — в папке `dist/`.

### B. Все три ОС сразу — GitHub Actions (рекомендуется)
`.github/workflows/build.yml` собирает на серверах GitHub под Win/Mac/Linux одновременно.
1. Залей проект в репозиторий GitHub.
2. Actions → Build ThingTracker → Run workflow.
3. Через ~10 мин скачай артефакты: thingtracker-windows / -macos / -linux.
Либо тег версии запускает сборку сам: `git tag v0.1.0 && git push origin v0.1.0`.

Порядок сборки (в скриптах уже прописан): фронт (`npm run build`) → бэкенд
(`pyinstaller thingtracker.spec`, он же вкладывает фронт внутрь бинарника) →
`electron-builder`.

## Телефоны (Android / iOS) — PWA
Отдельного файла-приложения нет: телефон не запускает Python. Мобильная версия —
это устанавливаемое веб-приложение (PWA), которое отдаёт десктоп.

1. На десктопе запусти ThingTracker (он поднимает сервер в локальной сети).
2. У доски нажми кнопку-ссылку 🔗 — там адрес вида `http://192.168.x.x:8766`.
3. На телефоне (та же Wi-Fi) открой этот адрес в браузере.
4. Меню браузера → «На экран «Домой»» / «Установить приложение». Появится иконка,
   открывается на весь экран как обычное приложение (manifest + иконки уже настроены).

Примечание: полноценная установка PWA со service worker требует HTTPS; по обычному
HTTP в локальной сети телефон всё равно добавляет ярлык на весь экран (manifest
работает), а офлайн-кэш включается только на защищённом соединении/localhost.

Полностью автономное мобильное приложение (без десктопа) — отдельный крупный этап
(перенос бэкенда на устройство, напр. через Capacitor/Tauri Mobile).

## Доступ из другой Wi-Fi сети (Tailscale)

LAN-режим работает только когда хост и гость в одной сети. Роутеры (NAT) не
пропускают входящие соединения снаружи, поэтому напрямую соединить людей на
разных сетях без посредника нельзя. Свой сервер поднимать НЕ нужно — проще всего
Tailscale:

1. Хост и гость ставят Tailscale (tailscale.com, бесплатно) и входят в один
   аккаунт/сеть Tailscale (можно пригласить гостя в свою сеть).
2. Хост запускает ThingTracker как обычно и смотрит свой Tailscale-IP в
   приложении Tailscale (This device -> IP вида 100.x.x.x).
3. В окне «Пригласить» переключить вкладку на «Другая сеть (Tailscale)», вставить
   этот 100.x.x.x — ссылка соберётся автоматически и запомнится.
4. Гость открывает ссылку в браузере. Всё, соединение идёт через защищённую
   мини-сеть Tailscale поверх интернета, сквозь любой NAT, без проброса портов.

Альтернативы: проброс порта на роутере (нужен белый IP, менее безопасно) или
туннель ngrok/cloudflared (временный публичный адрес, по сути сторонний
посредник). Tailscale ближе всего к «без своего сервера».
